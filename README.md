# ¿La comida boliviana puede cruzar fronteras?
La gastronomía boliviana forma parte importante de la identidad cultural del país. Existen platos tradicionales que representan distintas regiones y que también podrían llamar la atención de personas de otros países.

Dentro del proyecto Rutas Bolivianas, la comida puede formar parte de la experiencia turística, ya que conocer un lugar también implica conocer sus costumbres, ingredientes y platos tradicionales.

Algunos ejemplos de comida boliviana son:
- Salteñas
- Silpancho
- Pique macho
- Sopa de maní
- Anticucho
- Majadito
